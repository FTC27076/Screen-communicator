# Screen-communicator
Ill find a better name

This is my final hack club half-life designer project, and since this is freestyle, I want to do something that I've always thought about:
It's an esp 32 connected to a screen and a joystick. You type with the joystick, and press the joystick switch so that it sends the messgage. Then, the ESP uses something called ESPNOW to send it to another screen device thing. This would allow you to have basically a text based walkie-talkie.

# Materials

1. 12864 LCD
2. Ky-023 analog joystick with switch
3. ESP32-S3-wroom-1
4. 4XAA battery holder
5. Boot, enable and power switch
6. PCB
7. CASE
